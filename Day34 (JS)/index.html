Promises

A promise represents the eventual completion(or failure) of asynchronous operation and its returning/resulting value

JSON vs JS Object

JSON is a way of communication between web applications JSON format is understood by all languages and JS Object is only in JavaScript

JSON is a data format for data exchange and storage, while JavaScript objects are used for data manipulation and logic within code

It is language-independent and follows a strict syntax, requiring all keys and string values to be enclosed in double quotes, disallowing trailing commas and comments. JSON supports only a limited set of data types: strings, numbers, booleans, arrays, objects, and null, and cannot contain functions or executable code.

To convert between them, JavaScript provides the JSON.parse() method to convert a JSON string into a JavaScript object, and JSON.stringify() to convert a JavaScript object into a JSON string. This conversion enables seamless data transfer while preserving the structure and integrity of the data.

JS Object to JSON format

// JS Obj to JSON
const user = {
    name: "Gaurav",
    age: 20,
    profession: "software developer",
}

const jsonformat = JSON.stringify(user); 
console.log(jsonformat);

// JSON to JS Obj
const Jsondata = `{
    "name": "Aman",
    "age": 30,
    "city": "pune"
}`;

const Objformat = JSON.parse(Jsondata)
console.log(Objformat);

The .finally() Method

`.finally()` runs **regardless** of whether the promise succeeds or fails.

When to Use .finally()

Use `.finally()` for **cleanup code** that must always run:

- Hide loading spinners
- Close database connections
- Re-enable buttons
- Stop timers
- Release resources
