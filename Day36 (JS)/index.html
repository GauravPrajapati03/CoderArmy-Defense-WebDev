Prototypes in JS

Prototypes means that the object inherits some properties or methods from its elder parent in the prototype chaining

In JS Object don't have copies of methods; they have a link to another objects

First the Object looks into it if it doesn't find then it looks at its top-level Object and if it still doesn't find it then it go to one more level up and it comes till 'null' then it is not present or does not exists

This all is happening because of DRY(Do not Repeat Yourself) Principle which says that only write the code once which is reusable so when we write a function in Objects then it goes in the prototypes directly so that other functions can also use it if they inherit this Object Prototypes

Everything is at the end coming to Objects Prototypes the Objects, Arrays, Functions.Hence Everything is Object in JS
