JS is Single Threaded Synchronous Language

means js can perform only one task at a time

Synchronous means blocking

When JS is performing a heavy task then all other tasks are waiting and when it completes it execution then other tasks run synchronously

Web API

API in simple term is just like a function call whose definition we dont know

In web dev, Web API is a set of rules and protocols that allows different software applications to communicate with each other over the web or,

A Web API is like a messenger that lets one application request data or services from another application through the internet

Types of common Web APIS

  • Timer Apis(setInterval, setTimeout,...)
  • Network Apis(fetch, XMLHttpRequest)
  • DOM Events Apis(addEventListeners,..)
  • File Apis (Node.js)

JS never waits for any task

JS is Single Threaded, but browsers window is multi-threaded

JS Event loop is a mechanism that allows JS(single threaded) to handle asynchronous operations without blocking the main thread

Call Stack(JS executes code line by line), functions are pushed onto the stack and called and popped off the stack when finished execution

TASK QUEUES (Waiting area)
Microtask Queue (Promises) - HIGHER PRIORITY
Macrotask Queue (setTimeout, setInterval) - LOWER PRIORITY

Web API(Browser)

  • Handles Async tasks like:
    • setTimeout
    • fetch
    • DOM Events
    • File System(Node.js)
  • These run outside JS call Stack

Callback/Task Queue(Macro Task Queue)

  • Stores callbacks from async operations like:
    • setTimeout
    • DOM Events
    • setInterval

Micro Task Queue

  • Stores Microtasks from:
    • promises(.then)
    • Mutation Observers
  • Microtasks has higher priority than macro tasks
🔁 How the Event Loop Actually Works

1. JS executes code in the call stack.
When encountering an async function:

2. JS sends it to Web APIs.
Once the async operation completes:

3. Web API pushes its callback to the Task Queue (or Microtask Queue, depending on type).

4. Event Loop constantly checks:
If the call stack is empty → it pushes tasks from queues into the stack.

5. Microtasks run first, then macro tasks

JavaScript doesn't know or care if something is sync/async. It just calls functions and handles return values. The function's implementation (in browser) determines the behavior! 🎯
